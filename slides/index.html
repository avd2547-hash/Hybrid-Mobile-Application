แอปรวมกิจกรรมมหาวิทยาลัย — สร้าง · ลงทะเบียน · แจ้งเตือนก่อนกิจกรรม
Hybrid Mobile Application · Week 1–11
Expo (SDK 57) + React Native + TypeScript · iOS / Android / Web

ภาพรวมแอปและเทคโนโลยี

รวมความรู้คอร์สทั้งหมดในแอปเดียว

เนื้อหาที่เรียน (ภาพรวม)

  • เริ่มต้นโปรเจกต์และรันแอปด้วย Expo
  • Component, JSX, เทคนิค Styling
  • State / Lifecycle / Effects
  • ฟอร์ม + Validation
  • รายการ (List) และการค้นหา
  • Navigation และ Context แบบ global state
  • Media, Location, Map
  • Data persistence และ Notification

นำมาใช้ในงาน (ผลลัพธ์จริง)

  • สร้างกิจกรรมพร้อม เลือกวันเวลาจากปฏิทินไทย ได้
  • ลงทะเบียน / ยกเลิก / ลบกิจกรรม (แยกบัญชีผู้ใช้)
  • รายการโปรดต่อบัญชี ❤️
  • แผนที่ + ตำแหน่ง GPS + เส้นทางนำทางจริง 🧭
  • แจ้งเตือนล่วงหน้า — เวลาสำเร็จรูปหรือกำหนดเองเป็นนาที
  • รองรับ iOS / Android / Web ด้วยโค้ดชุดเดียว

Week 1 — เริ่มต้นและตั้งค่าโปรเจกต์

Expo · โครงโปรเจกต์ · การรันแอป

เนื้อหาที่เรียน

  • โครงสร้างโปรเจกต์ Expo + entry point
  • npm scripts (start / ios / android / web)
  • Debug เบื้องต้น, Expo Go

นำมาใช้ในงาน

  • แอปทั้งหมดอยู่บน app/ แบบ Expo Router (ไฟล์ = เส้นทาง)
  • รันทุกแพลตฟอร์มจาก package.json scripts เดิม
  • ทดสอบจริงผ่าน Expo Go บนมือถือ + เว็บ (port 8082)

Week 2 — Component, JSX, Props

สร้าง UI จากชิ้นส่วนที่ผนึกกัน

เนื้อหาที่เรียน

  • Function component และ props
  • แตก UI ซ้ำ ๆ เป็น component เล็ก
  • Props typing ด้วย TypeScript

นำมาใช้ในงาน

  • EventCard — การ์ดกิจกรรมใช้ซ้ำในหน้าแรก/รายการโปรด
  • RouteSteps, FeedbackStates (Loading/Error), OfflineBanner
  • DateTimePickerField — ปฏิทินไทย 2 สเต็ป (เลือกวัน → กรอกเวลา)

Week 3 — Styling และธีม

StyleSheet · สีเดียวทั้งแอป

เนื้อหาที่เรียน

  • StyleSheet, Flexbox layout
  • ธีมสี compose จาก object เดียว

นำมาใช้ในงาน

  • constants/Colors.ts — ธีม น้ำเงินกรม + ครีม + ทอง ใช้ทุกหน้า
  • สีที่นั่งอัตโนมัติ: getSeatStatus เขียว/ชมพูใกล้เต็ม/ชมพูเข้มเต็ม
  • Dark-header hero, ปุ่ม disabled, chip active ทั้งหมดมาจากธีมเดียว

Week 4 — State, Effects และ Lifecycle

useState · useEffect · useFocusEffect · cleanup

เนื้อหาที่เรียน

  • useState / useEffect dependency
  • การ cleanup, ยกเลิกงาน async
  • useRef เก็บค่าไม่ trigger render

นำมาใช้ในงาน

  • โหลดกิจกรรมด้วย AbortSignal — แท็บปิด/ออกจากหน้าจะ cancel โหลดจริง
  • useFocusEffect รีเฟรชรายการแบบเงียบ ๆ เมื่อกลับมาหน้า
  • hasDataRef แยก silent refresh กับ loading state แรก

Week 5 — ฟอร์มและ Validation

Controlled form · KeyboardAvoidingView · SafeArea

เนื้อหาที่เรียน

  • Controlled input, ตรวจสอบค่าก่อน submit
  • แสดง error รายช่อง + touched
  • Keyboard / notch handling

นำมาใช้ในงาน

  • ฟอร์มสร้างกิจกรรม app/(tabs)/create.tsx — validate ทุกช่อง + วันเวลาต้องเป็นอนาคต
  • ลิงก์ Google Maps ตรวจว่าอ่านพิกัดได้จริง
  • KeyboardAvoidingView + SafeAreaView ลื่นบน iPhone รอยบาก

Week 6 — รายการและการค้นหา

FlatList · ค้นหา · UX โหลดข้อมูล

เนื้อหาที่เรียน

  • แสดงรายการสเกลใหญ่อย่างมีประสิทธิภาพ
  • ค้นหา/กรอง + สถานะว่าง/โหลด

นำมาใช้ในงาน

  • หน้าแรก + รายการโปรด เรนเดอร์การ์ดเป็นรายการแนวตั้ง
  • Empty state ภาษาไทย + loading/error จาก FeedbackStates
  • สร้าง/ลบ/ยกเลิกแล้วรายการอัปเดตทันทีโดยไม่กะพริบ

Week 7 — Navigation

Tab · Stack · dynamic route

เนื้อหาที่เรียน

  • องค์ประกอบ navigation: tab, stack, modal
  • ส่งผ่าน parameter ระหว่างหน้า

นำมาใช้ในงาน

  • app/(tabs)/ — 5 แท็บ: หน้าแรก · สร้าง · รายการโปรด · โปรไฟล์
  • app/events/[id].tsx, app/register/[id].tsx — dynamic route ส่ง id
  • useLocalSearchParams — โหมดพิกัด override สำหรับทดสอบแผนที่

Week 8 — Context API (Global State)

เก็บ state ร่วมทั้งแอป ไม่ใช่เฉพาะต้นไม้ component

เนื้อหาที่เรียน

  • createContext / Provider / useContext
  • แยก context ตามหน้าที่

นำมาใช้ในงาน

  • AuthContext — session + accountKey ใช้เป็น key เก็บข้อมูลต่อบัญชี
  • FavoritesContext — toggle ❤️ ต่างหน้าจอเห็น state เดียวกัน
  • ทุก service เรียกด้วย accountKey — ล็อกอินชื่ออื่นจะไม่เห็นข้อมูลกัน

Week 9 — Media และ UI นวัตกรรม

Image picker · ไอคอน · ปุจฉาพาดข้อความ

เนื้อหาที่เรียน

  • เลือกรูปจากคลัง, ขอสิทธิ์, ตัดภาพ
  • ไอคอน + รูปแอป/สแปลช

นำมาใช้ในงาน

  • expo-image-picker — ใส่รูปเพิ่มให้กิจกรรม + ลบรูป (draft (ต้นฉบับที่ยังไม่ submit)) ได้
  • Hero รูปสาขา + ไอคอน/สแปลชของ KKU ใน app.json
  • ปุ่มทุกปุ่มมี accessibilityLabel ภาษาไทย

Week 10 — ตำแหน่งและแผนที่

GPS · แผนที่ · เส้นทางจริง

เนื้อหาที่เรียน

  • ขอและใช้ตำแหน่งผู้ใช้
  • ฝังแผนที่ + ปักหมุด

นำมาใช้ในงาน

  • expo-location — หมุดคุณอยู่ใกล้กิจกรรมแค่ไหน (ระยะ กม.)
  • EventMap — native ใช้ react-native-maps, เว็บใช้ iframe OSM อัตโนมัติตามแพลตฟอร์ม
  • เส้นทางขับจริง turn-by-turn จาก OSRM (routing.ts) + อ่านพิกัดจากลิงก์ Google Maps ที่แชร์มา

Week 11 — Data Persistence และ Notification

Storage ต่อบัญชี · เตือนใจก่อนกิจกรรม

เนื้อหาที่เรียน

  • บันทึกข้อมูลถาวร (storage / secure store)
  • ตั้งเวลาแจ้งเตือนระบบ

นำมาใช้ในงาน

  • AsyncStorage — กิจกรรม/รายการโปรด/ลงทะเบียน ต่อบัญชี (key ตาม accountKey)
  • SecureStore — ข้อมูลอ่อนไหวตามแพลตฟอร์ม (web = localStorage shim)
  • expo-notifications — แจ้งเตือนล่วงหน้า: ทันที / 5วิ / 30วิ / 5นาที / 30นาที / กำหนดเองเป็นนาที
  • Web fallback — ขอสิทธิ์ + setTimeout เตือนจริงบน browser

จุดเด่นต่อยอด (เกิน Week 11)

ฟีเจอร์ที่ตั้งใจเพิ่มเพื่อความสมบูรณ์

ปฏิทินไทย 2 สเต็ป

  • เดือนไทย + พ.ศ. พร้อมปุ่มเลื่อนเดือน
  • บล็อกวันที่ผ่านมา — ไม่ตั้งแจ้งเตือนย้อนหลังได้
  • หน้ากรอกเวลา: ชั่วโมง:นาที พิมพ์เอง + ชิปด่วน + ปุ่ม ±

แจ้งเตือนกำหนดเอง

  • เชื่อสำเร็จรูปหรือระบุนาทีเอง (เช่น 120 = 2 ชั่วโมงก่อน)
  • คำนวณจากวันเวลาเริ่มจริง — เตือนก่อนกิจกรรมพอดี

Web ระดับเดียวกับ Native

  • แจ้งเตือนบนเว็บด้วย Notification API
  • แผนที่ OSM + เขตข้อมูลต่อบัญชีเหมือนมือถือ
